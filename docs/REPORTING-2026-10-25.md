## 修复

三项管理入口保留面板功能，使用公开 SDK 的 finish(data=..., delivery="silent")，
并声明静态与运行时 result_kind="event"。成功的管理操作不再进入后台分析器的
主动任务完成播报；实际错误仍按错误回执处理。入口描述也明确不用于游戏行动。

最终 done 通知附上本地登记的原始指令和执行端实际回执。模型须报告具体成果与
未完成部分，不能把其他管理操作混成同一任务。原始结果、终态、去重、迟到结果、
恢复命令回执和通知待送机制保持，completed 仍不等于目标成功。

接单工具回执明确由角色通过游戏身体执行，不把工作转交给用户。
面板兼容原 Ok 返回形状与 SDK finish 信封，状态、结果和停止回执可继续读取。
